# Smart Study Pal

Create a simple education web app called SmartStudy AI.

Features:
- AI chatbot tutor for secondary school students
- Subjects: Mathematics, English, Biology, Government
- Quiz generator for students
- Simple dashboard showing learning progress
- Mobile friendly interface
